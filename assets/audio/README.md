# Sounds

Own work, no third-party material. The program reads the files at start
(`src/game/NightMazeApp.cpp`, through `audio::AudioEngine::load`) and plays them when the rules
in `src/game/SoundCues.cpp` say so. That file also holds the table that gives every sound cue
its file name.

All seven files are placeholders: mono, 16 bit, 44 100 samples per second, peak at about
-6 dBFS. They are computed from sine waves and noise, not recorded.

## Updating

Run `python tools/make_placeholder_sounds.py` from the repository root. The script writes the
same bytes every time, so the files only change when the script does.

To replace a placeholder by a real sound, keep the file name and the format (a WAV file: the
build of miniaudio decodes nothing else), and write its source, licence and author into the
table above.
