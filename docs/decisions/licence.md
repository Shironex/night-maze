# The code is MIT licensed and the assets are not covered by it
Status: accepted (2026-10-07)
Code: LICENSE, THIRD-PARTY-NOTICES.txt

Context: the repository became public so that the launcher can read releases without a token. A public repository with no licence file gives nobody any permission.
Decision: LICENSE holds the MIT text for the source code and a second part that keeps the assets all rights reserved: models, textures, sounds, video, interface art and story text. Shaders and menu files count as code.
Why: I want people to read and reuse the code but not copy the art and the story. Licensing everything under MIT lost because it hands out art I want kept.
Cost and revisit: the file does not say whether the rest of docs/ is covered. I reopen this if an asset arrives under a foreign licence.
