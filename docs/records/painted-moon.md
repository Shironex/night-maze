# The moon is painted into the sky cube map at the default light direction
Status: accepted (2026-10-05)
Code: tools/blender/make_skybox.py, src/game/Lighting.hpp, tests/SkyboxTests.cpp

Context: A lit night scene needs a visible moon, and the cube map is generated by a script outside the game.
Decision: The script paints the disc and glow opposite the default moon light (yaw 25, pitch minus 50), so the moon stands 50 degrees up. Sliders move the light, not the disc. A test checks the painted pixel against the defaults in game::LightingSettings.
Why: I rejected drawing the disc in skybox.frag from the current light because that adds a light uniform and much shader code for a case only my debug panel can cause.
Cost and revisit: The test tolerates about 2 degrees of drift, and a new direction means editing two files and running Blender. I reopen it if the moon light ever moves in play.
